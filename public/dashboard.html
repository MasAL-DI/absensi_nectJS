📖 Panduan Cepat
Import Excel:
1. Unduh template → isi data siswa
2. Upload file → klik Import

Daftarkan kartu RFID (ESP32):
1. Colokkan ESP32 ke komputer via USB
2. Klik Hubungkan ESP32 → pilih port COM
3. Klik nama siswa dari daftar
4. Tap kartu ke ESP32 → UID otomatis terbaca
5. Klik Simpan UID → lanjut siswa berikutnya

⚠️ Syarat: Harus pakai browser Chrome atau Edge.
💡 Tips: Tutup dulu Serial Monitor Arduino IDE sebelum hubungkan — tidak bisa dipakai bersamaan.
